📚 API Documentation

Seguimiento Legislativo Español - REST API v1.0

Overview

Esta API proporciona acceso a información sobre iniciativas legislativas del Congreso de Diputados y el Parlamento de Andalucía.

URL Base: http://localhost:5000

Formato: JSON

Cámaras Disponibles
Congreso de Diputados Cámara nacional del congreso español
Parlamento de Andalucía Parlamento autonómico de Andalucía
GET /api/stats

Obtiene estadísticas generales de una cámara legislativa.

Parámetros:
Parámetro Tipo Descripción Defecto
camara string Nombre de la cámara Congreso de Diputados
Ejemplo:
GET /api/stats?camara=Congreso%20de%20Diputados
Respuesta:
{
  "camara": "Congreso de Diputados",
  "total": 244,
  "estados": {
    "aprobada": 120,
    "rechazada": 45,
    "pendiente": 79
  },
  "ultima_actualizacion": "2026-05-19T10:30:00.000000"
}
GET /api/iniciativas

Lista iniciativas legislativas con filtros y paginación.

Parámetros:
Parámetro Tipo Descripción Defecto
camara string Nombre de la cámara Congreso de Diputados
pagina integer Número de página (desde 1) 1
por_pagina integer Items por página (máx. 100) 20
estado string Filtrar por estado (aprobada, rechazada, pendiente, retirada) ninguno
tipo string Filtrar por tipo de iniciativa ninguno
grupo string Filtrar por grupo autor ninguno
tema string Filtrar por temática ninguno
q string Búsqueda por palabra clave (título o resumen) ninguno
Ejemplo:
GET /api/iniciativas?camara=Congreso%20de%20Diputados&estado=aprobada&pagina=1&por_pagina=10
Respuesta:

Estados de Iniciativas
aprobada Iniciativa aprobada
rechazada Iniciativa rechazada
pendiente Iniciativa en tramitación
retirada Iniciativa retirada
Códigos de Error
Código Descripción
200 OK - Solicitud exitosa
400 Bad Request - Cámara no encontrada o parámetros inválidos
404 Not Found - Endpoint no encontrado
500 Internal Server Error - Error del servidor
